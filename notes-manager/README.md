# Notes Manager

A simple and interactive **Notes Manager** built with React.js. It provides an easy way to create, edit, delete, and manage notes through a clean and minimal user interface.

## Features

* Add new notes
* Edit existing notes
* Delete notes
* Mark and unmark notes as important
* Display total number of notes
* Responsive and user-friendly interface

## Technologies

* React.js
* JavaScript
* HTML5
* CSS3

## Installation

Clone the repository:

```bash
git clone https://github.com/YOUR-USERNAME/notes-manager.git
```

Navigate to the project directory:

```bash
cd notes-manager
```

Install dependencies:

```bash
npm install
```

Start the application:

```bash
npm start
```
